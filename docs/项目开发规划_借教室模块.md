## 项目概览

### 项目基本信息
- **项目名称**：交大教室租借和图书馆预定系统
- **子模块**：借教室模块（用户端）
- **开发周期**：8周
- **团队成员**：3人
- **你的分工**：需求分析 → 架构设计 → 前端开发 → 后端开发 → 集成测试 → 上线维护

### 核心业务流程提醒
```
登录 → 主页 → 选择借教室 → 填写需求(事由/容量/时间) 
→ 系统筛选可用教室 → 个性化查询 → 选择教室并提交 
→ 等待审核 → 查看结果
```

### 关键时间单位
- **讲次划分**：一般分为4-6个讲次，具体根据学校安排
  - 例如：第1讲 8:00-9:50、第2讲 10:00-11:50 等
  - 租借以讲次为单位（不是小时）

### 与其他模块的联系
- **借座位模块**（张涛）：类似流程，但时间单位为小时
- **管理员模块**（潘星宇）：负责审核你的申请，管理资源
- **共享数据**：用户表、教室表、通知系统

### 2.2 技术栈选择

#### 前端选择：微信小程序
**原因**：
- 官方指定
- 无需下载，用户体验好
- 与微信生态整合好

**关键技术点**：
- WXML (HTML-like)
- WXSS (CSS-like)
- JavaScript (ES6+)
- 微信小程序API

#### 后端选择：推荐 Node.js
**建议选择Node.js而非Java的原因**：
1. **与小程序云开发配合更好** - 微信云开发云函数支持Node.js
2. **开发效率更高** - JavaScript全栈
3. **对接微信API更便捷** - 第三方库支持完善
4. **部署更简单** - 直接部署在云开发平台

**后端框架推荐**：Express.js 或 Koa.js

#### 数据库：微信云开发数据库
**选择理由**：
- 官方配套，集成度最高
- 免运维，自动扩容
- 与小程序前端通信最快
- 实时数据库支持

#### 任务1.5：认证方案设计（第2周 1天）
**目标**：设计安全的用户认证流程

**认证流程**：
```
1. 前端获取微信登录信息
   ↓
2. 将微信code发送给后端
   ↓
3. 后端调用微信API换取session_key
   ↓
4. 生成JWT token返回前端
   ↓
5. 前端保存token，后续请求带上
   ↓
6. 后端验证token合法性
   ↓
7. 返回业务数据
```

**实现细节**：
- 使用JWT作为会话令牌
- Token过期时间：7天
- 支持自动刷新token
- 黑名单用户拒绝登录

```javascript
// pages/login/index.js
Page({
  data: {
    loading: false
  },
  
  onLoad() {
    // 检查是否已登录
    if (authUtil.isLoggedIn()) {
      wx.redirectTo({ url: '/pages/index/index' })
    }
  },
  
  handleWechatLogin() {
    this.setData({ loading: true });
    wx.login({
      success: (res) => {
        if (res.code) {
          // 调用后端接口交换token
          classroomAPI.login({ code: res.code })
            .then(result => {
              storage.setUser(result.data);
              wx.redirectTo({ url: '/pages/index/index' });
            })
            .catch(err => wx.showToast({ title: '登录失败' }))
            .finally(() => this.setData({ loading: false }));
        }
      }
    });
  }
});
```

```javascript
// 中间件：验证token
function authMiddleware(req, res, next) {
  const token = req.headers.authorization?.replace('Bearer ', '');
  
  try {
    const decoded = jwt.verify(token, config.jwt.secret);
    req.user = decoded;
    next();
  } catch (err) {
    return res.status(401).json({
      code: 401,
      message: 'token_expired'
    });
  }
}
```

```javascript
exports.main = async (event) => {
  const { capacity, date, lectures, building, equipment } = event;
  const db = cloud.database();
  
  // 1. 查询满足基本条件的教室
  let query = db.collection('Classroom').where({
    isRentable: true,
    capacity: _.gte(capacity)
  });
  
  if (building) {
    query = query.where({ building });
  }
  
  // 2. 逐个检查可用性
  const classrooms = await query.get();
  const available = [];
  
  for (let room of classrooms.data) {
    // 检查指定日期的讲次是否可用
    const conflicts = await db.collection('RentalApplication')
      .where({
        roomId: room._id,
        date,
        lectures: _.in(lectures),
        status: 'approved'
      })
      .count();
    
    if (conflicts.total === 0) {
      available.push(room);
    }
  }
  
  // 3. 过滤设备需求
  if (equipment && equipment.length > 0) {
    available = available.filter(room => 
      equipment.every(eq => room.equipment.includes(eq))
    );
  }
  
  return {
    code: 0,
    message: 'success',
    data: available
  };
};
```

```javascript
// 提交租借申请
exports.main = async (event, context) => {
  const { roomId, date, lectures, reason, requiredCapacity } = event;
  const { user } = context; // 从中间件获取用户信息
  const db = cloud.database();
  
  // 1. 验证教室和时间
  const classroom = await db.collection('Classroom')
    .doc(roomId)
    .get();
  
  if (!classroom.data[0]) {
    return { code: 404, message: 'classroom_not_found' };
  }
  
  // 2. 检查冲突
  const conflicts = await db.collection('RentalApplication')
    .where({
      roomId,
      date,
      lectures: _.in(lectures),
      status: 'approved'
    })
    .count();
  
  if (conflicts.total > 0) {
    return { code: 409, message: 'classroom_not_available' };
  }
  
  // 3. 生成申请编号
  const appNumber = generateApplicationNumber();
  
  // 4. 保存申请
  const result = await db.collection('RentalApplication').add({
    data: {
      userId: user.userId,
      roomId,
      date,
      lectures,
      reason,
      requiredCapacity,
      applicationNumber: appNumber,
      status: 'pending',
      createdAt: new Date().getTime(),
      updatedAt: new Date().getTime()
    }
  });
  
  return {
    code: 0,
    message: 'success',
    data: {
      applicationId: result._id,
      applicationNumber: appNumber,
      status: 'pending'
    }
  };
};

function generateApplicationNumber() {
  // 格式：RM20260510001 (RM+日期+序列号)
  const now = new Date();
  const date = now.toISOString().slice(2, 10).replace(/-/g, '');
  const random = Math.random().toString().slice(2, 5);
  return `RM${date}${random}`;
}
```

## 常见问题与解决方案

### 10.1 微信小程序相关

**Q1：如何处理小程序的域名限制？**
A：
- 所有请求URL必须在微信小程序后台配置
- 支持最多125个域名
- 只支持HTTPS
- 本地开发可在开发者工具中勾选"不验证合法域名"

**Q2：小程序如何保存登录状态？**
A：
```javascript
// 方案1：本地存储
wx.setStorageSync('token', token);

// 方案2：使用globalData
getApp().globalData.token = token;

// 建议：使用专门的状态管理库
```

**Q3：如何处理网络异常？**
A：
```javascript
wx.showLoading({ title: '加载中...' });
wx.request({
  success: (res) => { /* 处理成功 */ },
  fail: (err) => {
    wx.showToast({ title: '网络请求失败' });
    // 实现重试逻辑
  },
  complete: () => wx.hideLoading()
});
```

### 10.2 数据库相关

**Q1：如何在云数据库中实现事务？**
A：
使用云函数中的数据库事务：
```javascript
const db = cloud.database();
const transaction = db.startTransaction();

try {
  await transaction.update(...);
  await transaction.add(...);
  await transaction.commit();
} catch (err) {
  await transaction.rollback();
}
```

**Q2：如何优化查询性能？**
A：
- 添加合理的索引
- 使用分页而不是一次加载全部
- 避免复杂的嵌套查询

A：
在云函数入口文件配置：

```javascript
cloud.init({

});
```
