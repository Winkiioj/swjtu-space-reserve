# 西南交大空间预约系统 — 演示视频流程文档

> **版本**: 基于 `develop` 分支当前本地版本  
> **日期**: 2026-06-22  
> **预计视频时长**: 12–15 分钟  
> **演示角色**: 学生张三（借教室 + 选座）、管理员李四（审核 + 仪表盘）

---

## 一、演示准备

### 1.1 环境检查

在演示录制前，先完成以下准备工作：

1. **微信开发者工具**打开项目，确认云环境 `cloud1-d0gbgetcn91021db4` 已连接
2. 上传所有待部署云函数（见下方清单）
3. 运行初始化脚本，确保数据库有干净数据

### 1.2 待部署云函数清单

```
submitApplication, approveApplication, rejectApplication,
processReviewNotifications, getUserNotifications,
getUnreadNotificationCount, initTestClassrooms, initSeats, initTestData
```

### 1.3 数据初始化

在演示开始前，按以下顺序执行：

| 步骤 | 操作 | 说明 |
|:--:|------|------|
| 1 | 管理员 → 数据管理 → "一键重置测试环境" | 清空旧数据 |
| 2 | 确认 `dataStats` 云函数返回正常 | 验证 Classroom=20, Seat=180, User=11 |
| 3 | 确认 12 条测试申请已生成（覆盖4种状态） | 为审核演示做准备 |

### 1.4 录制设置

- 模拟器机型：iPhone 14 / 15（375×812 逻辑像素）
- 缩放：100%
- 底部 tabBar 始终可见
- 关闭开发者工具调试面板
- 录制前清除 Storage 缓存（模拟首次使用）

## 二、演示流程总览

```
第一部分：学生端 — 登录与首页 (1.5 min)
    ├── 微信登录
    ├── 学号绑定
    └── 首页浏览

第二部分：学生端 — 借教室流程 (3 min)
    ├── 三步向导：选时间 → 选教室 → 提交申请
    └── 查看申请列表

第三部分：学生端 — 选座流程 (2.5 min)
    ├── 选择日期+时段
    ├── 楼层→区域→座位三级筛选
    └── 确认预约 + 查看预约列表

第四部分：学生端 — 个人中心 (1.5 min)
    ├── 统计卡片 + 筛选跳转
    ├── 消息通知（入口+列表+已读）
    └── 取消申请演示

第五部分：管理员端 — 隐藏入口与仪表盘 (2.5 min)
    ├── 三击 Logo 进入管理员登录
    ├── 仪表盘：统计卡片 + 趋势图 + 热力图
    └── 通知中心

第六部分：管理员端 — 审核流程 (2.5 min)
    ├── 审核列表（搜索+筛选）
    ├── 通过一条申请（展示通知链路）
    ├── 拒绝一条申请
    └── 替代教室推荐 + 撤回审批

第七部分：总结收尾 (0.5 min)
    └── 功能矩阵回顾
```

**总时长**: 约 14 分钟

## 五、常见问题与应对

### Q1: 座位图显示不全？
- 确认 `initSeats` 云函数已部署并执行
- 检查 Seats 集合中 `thisDayStatusMatrix` 和 `nextDayStatusMatrix` 格式正确（13个元素的数组）

### Q2: 通知不显示？
- 确认 `getUserNotifications`、`getUnreadNotificationCount` 云函数已部署
- 检查 Notifications 集合存在
- 确认提交申请后 `submitApplication` 正常创建了通知记录

### Q3: 趋势图/热力图空白？
- 确认 `getAppTrends`、`getHeatmapData` 云函数已部署
- 检查返回数据格式与 `chart-helper.js` 匹配

### Q4: 管理员审批后申请状态未更新？
- 确认 `approveApplication` 是最新版本（含 `_shared/constants.js` 中的 `REVIEW_EXPIRY_MS`）
- 检查 `approvedClassroomId` 不为 undefined
