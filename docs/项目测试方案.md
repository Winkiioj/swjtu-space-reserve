| 级别 | 定义 | 标准 |
|------|------|------|
| **P0** | 阻塞性 | 核心流程无法使用，必须在上线前修复 |
| **P1** | 严重 | 重要功能异常，影响用户体验但可 workaround |
| **P2** | 一般 | 非核心功能异常或 UI 瑕疵 |
| **P3** | 建议 | 优化建议，不影响功能 |
