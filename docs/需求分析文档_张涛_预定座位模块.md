## 1. 前言

### 1.1 编写目的

本文档旨在为"交大图书馆座位预定系统"的用户借座位模块提供完整、清晰的需求分析。通过对师生借座位的业务流程、功能需求、数据要求进行详细定义，确保开发团队、测试人员及项目管理人员对模块预期功能达成共识。该模块将实现用户通过微信小程序查询图书馆空闲座位、按时段预定、实时占用状态等功能，提高图书馆座位利用率，优化师生学习体验。

### 1.2 读者对象

| 读者 | 说明 |
|------|------|
| 项目开发团队 | 负责前端、后端及数据库设计，需依据本文档实现座位查询、预定、状态管理等逻辑 |
| 项目管理人员 | 用于跟踪进度、风险识别及需求变更控制 |
| 系统测试人员 | 基于用例及业务流程设计测试用例，覆盖正常/异常场景 |

### 1.3 术语与缩写解释

| 术语/缩写 | 解释 |
|-----------|------|
| 图书馆座位预定系统 | 本系统子模块，面向交大师生提供在线查询、预定图书馆座位功能 |
| 时间段 | 以小时为最小租借单位，例如 08:00-09:00，可连续预定多个小时 |

## 2. 任务概述

### 2.1 主流程

#### 2.1.1 流程图

```
登录 → 进入借座位界面 → 查询条件输入 → 系统筛选空闲座位
  → 浏览并选择座位 → 提交预定 → 异常处理/成功反馈 → 完成
```

#### 2.1.2 流程说明

| 步骤 | 描述 |
|------|------|
| **步骤1：用户登录** | 使用交大统一认证账号登录，系统获取用户身份（学号/教职工号） |
| **步骤2：进入借座位界面** | 主页面展示"图书馆座位预定"入口 |
| **步骤3：查询条件输入** | 用户选择预定日期、起始小时和结束小时（最小1小时，最长4小时，可配置），系统自动校验开放时间段（如 8:00-22:00） |
| **步骤4：系统筛选空闲座位** | 根据时间段遍历座位表，过滤已预定/占用的座位，返回该时段所有空闲座位所属区域列表，并可展示座位分布热力图 |
| **步骤5：浏览并选择座位** | 用户查看空闲座位编号、位置、设施信息，点击选择意向座位 |
| **步骤6：提交预定** | 系统开启事务，再次检查所选座位在选定时间片内是否仍空闲，若无冲突则创建预定记录（状态为有效），更新座位时段占用表，返回预定成功及二维码/签到码 |
| **步骤7：异常处理** | 如遇并发冲突，提示用户重新选择。预定成功后，座位状态置为占用，并同步显示在实时地图中 |

#### 2.1.3 作业分解

| 作业代码 | 作业描述 | 操作员 | 输入/输出 |
|----------|---------|--------|----------|
| LIB-01 | 登录身份验证 | 师生用户/系统 | 输入：账号密码；输出：会话 Token |
| LIB-02 | 输入查询时间段并检索空闲座位 | 师生用户 + 系统 | 输入：日期、起始/结束小时；输出：空闲区域列表及座位详情 |
| LIB-03 | 系统根据时间段筛选空闲区域 | 系统自动 | 查询座位占用表，筛选无重叠预定的座位，按区域分组展示 |
| LIB-04 | 选择座位并提交预定申请 | 师生用户 | 选定座位编号，发起预定请求 |
| LIB-05 | 并发控制及预定写入 | 系统自动 | 验证时段冲突，生成预定单，更新座位状态，返回预定凭证 |
| LIB-06 | 成功反馈及状态更新 | 系统自动 | 界面提示"租借成功"，个人预定列表刷新，座位状态变更为占用 |
| LIB-07 | 预定失败重新选择 | 系统 + 用户 | 冲突时提示重新选择其他座位，返回 LIB-04 |

### 3.2 用例说明

#### UC-LIB-01：根据时间段查询空位

| 项目 | 内容 |
|------|------|
| **用例编号** | UC-LIB-01 |
| **用例名称** | 根据时间段查询空位 |
| **参与者** | 交大师生用户 |
| **前置条件** | 用户已登录系统；图书馆座位数据已初始化（含区域、座位及固定课表/节假日配置） |
| **主事件流** | 1. 用户进入借座位页面，选择日期及起止时间(小时粒度)；2. 系统验证时间段是否在允许范围内(08:00-22:00)；3. 系统查询该时间片内所有未被占用的座位；4. 按区域分组返回空闲座位列表及空闲区域概览 |
| **后置条件** | 系统展示可用座位地图，用户可进一步选择预定 |
| **备选流** | 若无空闲座位，系统提示"当前时段无空位，请更换时间"；若查询时间超出可预约范围，提示修改 |

#### UC-LIB-02：选择空位并成功租借

| 项目 | 内容 |
|------|------|
| **用例编号** | UC-LIB-02 |
| **用例名称** | 选择空位并成功租借 |
| **参与者** | 交大师生用户 |
| **前置条件** | 已完成空闲座位查询，且座位在所选时段空闲 |
| **主事件流** | 1. 用户浏览座位列表，点击某个空闲座位；2. 系统弹出确认框显示座位号、时段等信息；3. 用户确认预定；4. 系统加锁并再次校验该座位在该时段是否未被占用；5. 生成预定记录，修改座位时间片状态为已预定；6. 返回预定成功消息及电子凭证；7. 更新前端座位地图显示占用 |
| **后置条件** | 座位被当前用户锁定占用，他人无法在同一时段预定；预定记录持久化 |
| **异常流** | 若提交时座位已被其他人抢先预定，系统回滚并提示"预定失败，座位已被占用，请重新选择" |
| **业务规则** | 同一用户同一时段只能预定一个座位；单次预定最长时间不超过4小时，可提前2天预约 |

#### UC-LIB-03：查看/取消预定

| 项目 | 内容 |
|------|------|
| **用例编号** | UC-LIB-03 |
| **用例名称** | 查看/取消预定 |
| **参与者** | 师生用户 |
| **前置条件** | 用户已存在有效的预定记录 |
| **事件流** | 用户进入"我的预定"列表，查看预定详情；若需取消，点击取消按钮，系统释放该座位在该时间段的占用，更新状态为空闲；若取消时间距开始时间不足30分钟，按违约记录处理 |
| **后置条件** | 座位释放，其他用户可预定；违约次数+1（若适用） |
